# gr4 routine role statements, tier-2 batch 3

Each statement comes from the rendered facts for one routine in the mgras.a members named in its
header: register loads and stores, calls, constants and branch shapes at the addresses cited.
Addresses are virtual addresses in the named binary. Where the facts do not settle a meaning, the
statement says so.

- `irix5_to_mgras_pointers_xlate` in `usr/cpu/sysgen/IP28boot/mgras.a(mgras_dma.o)` at 0x2ecc
  **Inferred.** Appears to convert a pointer table from the older 32-bit layout to the 64-bit layout. It calls kern_malloc at 0x2f58 with a0 set to a2 times 4, skipping that call when the size is zero (the beq at 0x2ed8). It reads a 4-byte count from a3 at +0x0 and an 8-byte field at +0x8, then stores 8-byte fields at +0x10 (0x2f3c, 0x2f64). The success return is 0 at 0x2f18, and the facts do not settle which argument is the input table.

- `irix5_to_mgras_dma_flush_defn_xlate` in `usr/cpu/sysgen/IP28boot/mgras.a(mgras_dma.o)` at 0x2f74
  **Inferred.** Appears to convert a DMA flush definition between the same two layouts, with 8-byte entries. The allocation is a2 times 8 bytes through kern_malloc at 0x3008, and the 4-byte load at 0x2fa4 is stored as an 8-byte value at 0x2fa8. It returns 0 at 0x2fc8. Which side is source and which is destination is inferred from the widths only.

- `irix5_to_mgras_dma_replace_defn_xlate` in `usr/cpu/sysgen/IP28boot/mgras.a(mgras_dma.o)` at 0x3024
  **Inferred.** Appears to convert a DMA replace definition with the same pattern as its neighbors at 0x2ecc and 0x2f74. It calls kern_malloc at 0x30c8 and stores 8-byte values at +0x10 (0x30ac, 0x30d4) from fields it loads at +0x0 and +0x8 of the same block, with a 4-byte store at +0x4 (0x30b4). It returns 0 at 0x3080. The size argument to kern_malloc is not resolved by the facts.
