# Source documents

Every published document the project found that bears on IMPACT graphics (Indigo2 Solid, High and Maximum IMPACT; Octane SI, SSI, MXI and the E-series boards). Files are stored unmodified. Each row gives the SHA-256 of the stored file and the URL it was first fetched from.

The Octane technical report is stored one level up as `docs/octane-technical-report.pdf` (SHA-256 `248e73ee94f53c7e49e548503180b4f361d3ed19c4183cfcaa42edddc812aff0`, source `http://www.sgidepot.co.uk/octane/octane-technical-report.pdf`).

`sha256sum -c SHA256SUMS` run in this directory verifies every file.

Facts mined from these documents are in [../IMPACT_BOARD_FACTS.md](../IMPACT_BOARD_FACTS.md).
