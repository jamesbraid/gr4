# te1

Texture Engine 1 (TE1), TETRAM Controller (TR1), and Texture Subsystem for SGI Impact (GR4).

Texture engine and texture RAM registers and loader registers of the Impact graphics subsystem.

Source: driver readings.

[TE1.h](TE1.h) is the commented C description of the chip; the values are in [registers.toml](registers.toml), each graded and sourced, and the generated reference page is [registers.md](registers.md).
