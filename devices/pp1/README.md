# pp1

Pixel Processor 1 (PP1), Rambus RDRAM, and RAC Architecture for SGI Impact (GR4).

Display read buffer registers of the Impact graphics subsystem.

Source: driver readings.

[PP1.h](PP1.h) is the commented C description of the chip; the values are in [registers.toml](registers.toml), each graded and sourced, and the generated reference page is [registers.md](registers.md).
