# ge11

Geometry Engine 11 (GE11) Vector Floating-Point Processor for SGI Impact (GR4).

Geometry engine control registers of the Impact graphics subsystem.

Source: driver and diagnostic readings.

[GE11.h](GE11.h) is the commented C description of the chip; the values are in [registers.toml](registers.toml), each graded and sourced, and the generated reference page is [registers.md](registers.md).
