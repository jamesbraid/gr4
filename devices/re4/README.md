# re4

Raster Engine 4 (RE4) and Raster Subsystem (RSS) Architecture for SGI Impact (GR4).

Raster engine registers of the Impact graphics subsystem.

Source: driver and traffic readings.

[RE4.h](RE4.h) is the commented C description of the chip; the values are in [registers.toml](registers.toml), each graded and sourced, and the generated reference page is [registers.md](registers.md).
