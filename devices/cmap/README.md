# cmap

Colormap ASICs (CMAP0, CMAP1), TrueColor RAMDAC, and XMAP Display Router for SGI Impact (GR4).

[CMAP.h](CMAP.h) is the commented C description of the chip.

[registers.md](registers.md) is the graded register map, generated from `registers.toml`.
